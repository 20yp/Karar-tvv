# KARAR TV

A lightweight custom Android TV launcher for the TCL R4.

## Target device
- Android TV 11
- Realtek RTD2851M
- ARM 32-bit (`armeabi-v7a`)
- 2 GB RAM

## Design goals
- tvOS-inspired home screen
- Cinematic backgrounds with a 30% dark overlay
- Favorites for YouTube, Netflix, Shahid, Prime Video, Google Play, and Settings
- Clock in the top-right corner
- Clear remote-control focus indicator
- Add, remove, and reorder apps using the remote
- No ads, news feed, recommendations, or heavy network polling
- Responsive layout for 1080p and 4K displays

## Build status
Project source and Android build workflow are not yet committed. The first implementation must be built and tested before changing the TV's default launcher. Google TV and ATV Launcher remain fallback options.
